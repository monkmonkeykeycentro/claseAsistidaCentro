# Directorio de Archivos Públicos (Vite)

Coloca aquí tus archivos multimedia estáticos para que estén disponibles directamente en la aplicación.

## Video principal del ejercicio
- Archivo: `video.mp4`
- Ruta completa: `/public/video.mp4`
- URL servida en la web: `/video.mp4`

Cuando agregues tu archivo `video.mp4` en esta carpeta, el reproductor de la página principal lo cargará y procesará automáticamente con el efecto interactivo de Código Creativo ASCII.
